# Letters to Heaven

**A quiet place for what remains**

A gentle, private web app for writing letters to loved ones who have passed and for grief journaling.

## Features

- **Write letters** addressed to anyone you miss — unfinished words, updates, gratitude, anger, or simple remembrance
- **Grief journaling prompts** organized by theme:
  - Missing & Remembering
  - Emotions & the experience of grief
  - Unfinished business & connection
  - Meaning, legacy & moving forward
- **Memory Jar** — capture ordinary and precious memories so they don't fade
- **Vault** — keep letters private, light a candle when revisiting, release when ready
- Everything stored locally in your browser (no accounts, no tracking)

## How to use

Open `index.html` in any modern browser.

You can also enable GitHub Pages on this repository to host it online.

## Design

Soft dark night-sky aesthetic with elegant typography. Built to feel calm and unhurried.
