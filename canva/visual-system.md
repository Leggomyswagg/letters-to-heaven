# Letters to Heaven — Canva Visual System

## Palette
- Deep navy: #101A2B
- Warm cream: #F7EDCF
- Muted gold: #D5AA55
- Soft sage: #B8C8A7
- Charcoal ink: #20261F

## Typography
Use an elegant serif for letters and emotional headlines, paired with a clean sans-serif for navigation, metadata, and controls.

## Visual language
Quiet, private, reverent, warm. Use restrained candle/star marks, paper-like letter surfaces, botanical keepsakes, and rounded cards. Avoid clinical or overly sentimental styling.

## Template ideas
1. Letter keepsake card
2. Memorial date reminder
3. Candle-lighting share card
4. Memory prompt card
5. App landing-page hero
